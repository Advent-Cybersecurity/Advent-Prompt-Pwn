# Security Policy

## Supported versions

Version 1.x receives security fixes. Before a public release exists, fixes are applied to the latest revision on the default branch.

## Reporting a vulnerability

Please use the repository's private vulnerability-reporting feature. If the repository has not been published yet, contact Advent Cybersecurity through the contact method listed at [adventcybersecurity.com](https://www.adventcybersecurity.com/).

Include:

- A description of the affected component
- Reproduction steps using synthetic data
- The security impact
- A suggested remediation, if known

Do not place live credentials, customer data, or third-party target information in a report. We will acknowledge receipt, investigate, and coordinate disclosure before publishing details.

## Scope of this policy

Security issues include scope-control bypasses, credential leakage, unsafe report handling, dependency compromise, and behavior that contacts an undeclared endpoint. Model refusal failures found during an authorized assessment are assessment results, not vulnerabilities in this framework.
