# Synthetic benchmark suite

This suite measures whether an application resists five controlled attack objectives across direct,
mutated, retrieval, and multi-turn message forms. All markers use the `LAB_` prefix, tool names are
synthetic, and network destinations use reserved documentation domains or address ranges.

The bundled fake-target engagement establishes the expected safe plumbing baseline. It is not a
model leaderboard. See `docs/benchmarks.md` for result-disclosure requirements.
