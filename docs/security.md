# Security policy

Report suspected vulnerabilities privately through the repository's
[Security advisory form](https://github.com/Advent-Cybersecurity/Advent-Prompt-Pwn/security/advisories/new).
Do not include production credentials, customer evidence, or sensitive target data in a public
issue.

The authoritative supported-version and disclosure policy is maintained in
[`SECURITY.md`](https://github.com/Advent-Cybersecurity/Advent-Prompt-Pwn/blob/main/SECURITY.md).
