# Naming Decision

The selected public project name is `advent-prompt-pwn`.

| Surface | Name |
|---|---|
| Public project | `advent-prompt-pwn` |
| PyPI distribution | `advent-prompt-pwn` |
| Command line | `advent-prompt-pwn` |
| Python import | `advent_prompt_pwn` |

Python identifiers cannot contain hyphens, so the import namespace uses underscores while the public, installation, and command names use hyphens.

A preliminary exact-name search did not identify an indexed package or AI-security project using the selected name. This is not trademark clearance or a registry reservation. Before public promotion, reserve the PyPI project and source repository, repeat the exact-name search, and complete the LLC's normal name-clearance process.
